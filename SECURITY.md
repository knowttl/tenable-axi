# Security

Report suspected vulnerabilities privately through [GitHub's security advisory reporting](https://github.com/knowttl/tenable-axi/security/advisories/new).
Include the affected command, observed behavior and a minimal synthetic reproduction.
Do not include credentials, tenant responses, customer identifiers or private infrastructure details.
Avoid public issues for unpatched vulnerabilities.

See [write safety](docs/safety.md) and [credential configuration](docs/configuration.md) for the security boundaries.
