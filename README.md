# tenable-axi

An AXI command-line tool for Tenable One, under construction.
The planned implementation uses TypeScript on Node.js 22 and will be published as `@knowttl/tenable-axi`.
No executable or npm package is available from this design slice.

See the [design](docs/design.md) for v1 scope, credentials, write policy, verification, and implementation slices.
